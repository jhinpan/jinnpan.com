Open Source PR Tracker

The board

Every pull request in the window, one row each, grouped by the thread it advances. A bar runs from the day it opened to the day it merged, closed, or — if still moving — to today. Filters scope the cards below too.

Threads

The workstreams these pull requests belong to — why each exists, which goal it serves, and its next move. This is the view to re-read before deciding what to do next.

Landed

Authored and merged inside the window. What each one changes, why it had to exist, and what the review taught.

In flight

Open pull requests I own, the ones waiting on me first. Each says exactly what it is waiting on and the single next step.

Needs a decision

Open, but not moving: fixtures whose experiment is over, drafts nobody was asked to read, work that landed elsewhere. Each carries the call to make — close, re-cut, or keep.

Reviewed for others

Pull requests by teammates where my review shaped the outcome — merged ones first, then the ones still open.

Closed without merging

Work that stopped. Each one carries a decision: revive, re-target, or let go.

Blockers

What is actually stopping the next result.

Questions

Open calls that need another person to settle.

Ideas

Worth discussing, not yet committed to.
